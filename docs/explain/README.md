# คำอธิบายโค้ด

ไฟล์ในโฟลเดอร์นี้อธิบายว่าโค้ดแต่ละส่วนทำอะไร ทำไมเขียนแบบนั้น และคำถามที่มักถูกถามกับจุดนั้น
หนึ่งไฟล์ต่อหนึ่ง task ตามแผนใน `docs/superpowers/plans/`

| ไฟล์ | เนื้อหา |
|---|---|
| `task-01-scaffold-and-config.md` | โครงโปรเจกต์ การอ่านค่าตั้ง การเชื่อมฐานข้อมูล และเทสต์ตัวแรก |
| `task-02-users-table-and-migrations.md` | ตาราง users, Alembic migration, constraint ในฐานข้อมูล และโครงเทสต์ |

เอกสารอ้างอิงอื่น

- `new_scenario_summary.md` — ข้อกำหนดของระบบ
- `screens.md` — หน้าจอ 18 หน้าและสิทธิ์
- `data_model.md` — โครงสร้างฐานข้อมูลทั้งหมด
